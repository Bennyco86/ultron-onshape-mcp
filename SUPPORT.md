# Ultron Onshape MCP support

For help, reproducible defects, and feature discussions, use the public issue
tracker:

<https://github.com/Bennyco86/ultron-onshape-mcp/issues>

## Before opening an issue

Check the README, known limitations, and existing issues. A useful report includes:

- the Ultron commit or release you are using
- your Claude Code and `uv` versions
- the failing MCP tool and smallest request that reproduces the issue
- the compact structured response, including warnings and hints
- what you expected to change in Onshape and what changed instead
- whether the same problem occurs in a new test document

If possible, use a minimal document that contains no confidential work.

## Never share credentials

Do not include `ONSHAPE_API_KEY`, `ONSHAPE_API_SECRET`, keychain output, private
document identifiers, customer data, or proprietary drawings in an issue, log,
screenshot, or sample configuration.

Revoke and replace an API key immediately if it is exposed.

## Project scope

Support covers the Ultron fork, documented setup, and reproducible MCP behaviour.
It cannot provide an Onshape account, general CAD training, or engineering approval
for generated geometry. Review all output before manufacture or safety-critical use.

Ultron Onshape MCP is independent and is not affiliated with or endorsed by
Onshape or PTC.
